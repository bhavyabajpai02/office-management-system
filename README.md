# Momentum AI

Momentum AI is an AI-powered enterprise workflow and performance management platform designed to streamline employee goal tracking, approvals, quarterly check-ins, analytics, escalations, and organization-wide workflow visibility.

---

## Features

- Employee Goal Management
- Quarterly Check-Ins
- AI Copilot Assistant
- Manager Approvals
- Team Analytics
- Organization Analytics
- Audit Logs
- Escalation Management
- Activity Feeds
- Role-Based Dashboards
- Enterprise Workflow Engine
- Real-Time State Propagation

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS

### Backend / Data
- Supabase
- Local workflow engine
- Demo state persistence

---

## Demo Access

Momentum AI supports role-based demo access.

### Employee
- Create goals
- Submit check-ins
- Use AI Copilot

### Manager
- Review approvals
- Team analytics
- Employee feedback workflows

### HR/Admin
- Analytics
- Audit logs
- Escalations
- Permissions management

Use the role selector on the login page to switch between journeys.
